# img

图床 —— 打开网页粘贴或拖拽图片，立刻拿到直链，**无需注册、无需令牌**。

## 在线地址

**https://polytrack114514.github.io/img/**

## 怎么用

1. 打开上面的网址
2. 三种上传方式任选：
   - 直接 **Ctrl + V 粘贴** 剪贴板里的图片（截图后不用存盘）
   - 把图片 **拖进** 虚线区域
   - 点虚线区域 **选择图片**（支持多选）
3. 图片会自动上传并出现在「图库」里，每张图下方有三个复制按钮

上传时会自动改名成 `原文件名-4位随机码.扩展名`；`image`、`blob`、`screenshot`、`clipboard` 这类通用名会换成 `img-年月日-时分秒` 形式。**同名图片可以直接上传**，后端会自动加序号保存为 `名字-1.扩展名`、`名字-2.扩展名`……，老图片和已经分享出去的链接都不会失效。

## 四种链接

点图库里的图片可以放大预览，预览窗口和图库里都能拿到这些链接：

| 形式 | 用途 |
| --- | --- |
| 直链 | `https://polytrack114514.github.io/img/xxx.png`，直接贴进浏览器或软件里 |
| Markdown | `![xxx](直链)`，写文档、写博客用 |
| HTML | `<img src="直链" alt="xxx" />`，写网页用 |
| 下载 | 走后端 `/download`，强制下载而不是在浏览器里打开 |

图库按**上传时间倒序**排列，最新的在最前；标题旁会显示图片数量和总占用空间。图库上方有搜索框，按文件名实时搜索；下面两排标签分别按**图片格式**（PNG / JPG / GIF…，数量由实际图片统计）和**上传时间**（今天 / 最近 7 天 / 最近 30 天）筛选，可叠加使用，标题会显示「筛选出 X / Y 张」。

手机浏览器同样可用：网格会自动变窄成两到三列，按钮和预览窗口都做了窄屏适配。

## 删除与回收站

每张图右侧有「删除」。删除是**软删除**：图片会被挪到仓库的 `.trash/` 目录，页面右上角「回收站」里能找到它，并可以：

- **恢复**：原路放回图库
- **彻底删除**：真正从仓库里删掉
- **清空回收站**：一次删掉全部

回收站里的图片同样占用仓库空间，确认不要了记得彻底删除。

**上传和删除需要口令或访问令牌**：在「上传图片」卡片的口令框里输入，浏览器会记住；由后端校验，不填或填错一律 `403`，绕过网页直接调接口同样无效。浏览和下载不需要口令。

## 访问令牌（可单独吊销）

口令只有一个，谁用过都复制得到，想收回某台设备的权限只能换口令、全体重输。令牌解决这个问题：

1. 在口令框里输入**主口令**（管理员口令），点旁边的「令牌」
2. 「生成新令牌」→ 起个名字（比如「公司电脑」）→ 得到 `img_xxxxxxxx…`
3. 把令牌填进那台设备的口令框即可，它和主口令一样能上传、删除
4. 那台设备不用了，在图库里点「吊销」，**立刻失效**，其他设备不受影响

令牌只能查看、生成、吊销，不能反向管理令牌，所以拿到令牌的设备收不回管理员权限。令牌存在 Cloudflare KV（绑定名 `TOKENS`），不需要重新部署就能生效。

## 隐藏的图床

上传卡片右边的「隐藏的图床」按钮，是给**不能公开**的图片用的：

- 这些图片**不写入 GitHub 仓库**，而是存在 Cloudflare KV（绑定名 `SECRET`），所以没有任何可以公开打开的直链，`https://polytrack114514.github.io/img/文件名` 会 404
- 列表、查看、删除都要先在口令框里输入口令（主口令或访问令牌都能用）
- 每张图用「查看」在弹层里显示（走接口取图，前端转成临时 blob，不落缓存），用「链接」复制分享地址
- 分享地址形如 `https://polytrack114514.github.io/img/?secret=文件名`，对方打开后必须输入口令才能看到图片
- 单张最多 **10 MB**（KV 单值 25 MB 的上限），同名会自动加序号
- 删除是彻底的，没有回收站

KV 免费额度是 1 GB 存储、每天 1000 次写入，够个人放少量私密图；大量存放不适合。

## 架构

```
浏览器（GitHub Pages 页面）
        │  POST /upload  /delete  /trash   GET /list  /stats  /download  /trash
        ▼
Cloudflare Pages 后端  https://img-bed-84l.pages.dev
        │  携带 GitHub 令牌
        ▼
GitHub 仓库 polytrack114514/img
```

- 前端：本仓库 `index.html`，由 GitHub Pages 托管，是纯静态页面
- 后端：Cloudflare Pages 上的 `_worker.js`，持有 GitHub 令牌，对外提供上传/删除/列表接口
- 前端通过仓库里的 `backend.json` 得知后端地址：

```json
{ "workerUrl": "https://img-bed-84l.pages.dev", "password": "" }
```

后端环境变量：

| 变量 | 值 |
| --- | --- |
| `GH_TOKEN` | 加密变量，GitHub 令牌（不对外暴露） |
| `REPO_OWNER` | `polytrack114514` |
| `REPO_NAME` | `img` |
| `BRANCH` | `main` |
| `ALLOW_ORIGIN` | `https://polytrack114514.github.io` |
| `UPLOAD_PASSWORD` | 加密变量，主口令（管理员口令，已设置） |

另有 KV 绑定：

| 绑定 | 说明 |
| --- | --- |
| `TOKENS` | Cloudflare KV 命名空间 `img-tokens`，存访问令牌 |
| `SECRET` | Cloudflare KV 命名空间 `img-secret`，存隐藏图床的图片 |

## 保护机制

`backend.json`、`index.html`、`README.md`、`worker.js` 这四个基础文件受后端**强制保护**：覆盖或删除一律 `403`，即使绕过网页直接调接口也无效。图片只在仓库根目录存放，文件名不能与这四个文件重名。

## 限制

- 单张图片最大 **20 MB**，前端与后端双重校验，后端超限返回 `413`
- 只接受图片扩展名：`jpg` `jpeg` `png` `gif` `webp` `svg` `bmp` `avif` `ico` `tif` `tiff` `heic` `apng` `jfif`，其他类型返回 `415`
- 本仓库是**公开仓库**，上传的图片任何人可见，请勿存放私密内容
- `.meta.json` 由后端自动维护，记录每张图的上传时间，界面不显示，请勿手改
- `.trash/` 是回收站目录，界面不显示，不参与统计，但占用仓库空间

## 接口

- `GET /list` 根目录图片列表（带 `uploadedAt`，按时间倒序）
- `GET /stats` 图片数量、总字节数、是否需要口令
- `GET /trash` 回收站列表
- `GET /download?name=文件` 强制下载
- `POST /upload` 上传（需主口令或令牌）
- `POST /delete` 软删除到回收站（需主口令或令牌）
- `POST /trash` `action=restore|purge|empty`（需主口令或令牌）
- `POST /tokens` `action=list|create|revoke`，管理访问令牌（只接受主口令）
- `POST /secret/list` 隐藏图床列表（需口令）
- `POST /secret/upload` 上传隐藏图片（需口令）
- `POST /secret/image` 取隐藏图片二进制（需口令）
- `POST /secret/delete` 删除隐藏图片（需口令）
